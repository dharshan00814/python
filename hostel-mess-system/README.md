# Hostel & Mess Management System (Full-Stack)

This folder contains a full-stack project:
- **Backend**: Node.js + Express + MongoDB (Mongoose) + JWT admin auth
- **Frontend**: React + TailwindCSS + React Router

## Backend
See `backend/.env.example` for required environment variables.

## Frontend
Frontend expects the backend base URL via `VITE_API_BASE_URL`.
